# 運用連絡票PDF生成マッピング定義 (詳細版)

特ラ機構指定の「運用連絡票」PDFへの、アプリケーションフォームデータの詳細マッピング仕様。

## 0. 生成戦略
本アプリでは、レイアウトの正確性と保守性を高めるため、以下のフローでPDFを生成する。
1. **データ収集**: ユーザーが入力したフォームデータとDBの会員情報を統合。
2. **Excel転記**: 特ラ機構提供のExcelテンプレート (`master.xlsx`) にデータを流し込む (`openpyxl` を使用)。
3. **PDF変換**: 書き込み済みのExcelデータをPDF形式に変換してブラウザへ出力する（プレビュー用）。

## 1. 申請区分 (左上)
フォームの `app_type` ラジオボタンの選択結果を反映する。

| フォーム値 | PDF描画内容 | 描画位置 |
| :--- | :--- | :--- |
| `new` | 「新規」という文字または太枠 | 左上「新規」枠内 |
| `change` | 「変更」という文字または太枠 | 左上「変更」枠内 |
| `delete` | 「削除」という文字または太枠 | 左上「削除」枠内 |

## 2. 共通ヘッダー・会員情報
ログイン中の `Member` モデルから自動取得。

| PDF項目名 | 取得元データ | 備考 |
| :--- | :--- | :--- |
| 提出日 | システム日付 | YYYY/MM/DD |
| 会員番号 (左) | `Member.member_id_1` | 3桁 |
| 会員番号 (右) | `Member.member_id_2` | 4桁 |
| 会員名 | `Member.name` | |
| 部署 | `Member.department` | |
| 運用担当者 | `Member.manager_name` | |
| Tel | `Member.phone` | |
| E-mail | `Member.email` | |

## 3. 現地使用者・催事情報
フォームの「申請内容入力」セクションから取得。

| PDF項目名 | フォームID / 取得ロジック | 描画形式例 |
| :--- | :--- | :--- |
| 氏名（ふりがな） | `user_name` + `user_kana` | 立石 智史（たていし さとし） |
| Tel | `user_tel` | 090-2051-5474 |
| E-mail | `user_email` | s-tateishi@... |
| **催事名** | `event_name` | ハムレット (ピンク背景部分) |
| コメント | `comment` | 変更内容や伝達事項 |

## 4. 使用マイク数テーブル (中段)
フォームの「使用マイク数」テーブル（マトリクス）の数値を反映。

-   **アナログ RM / 〃 EM / デジタル RM** の各行に対し、**TV WS / 53ch / 1.2G** の各列の数値を描画。
-   **53ch併用フラグ**: フォームの `toggle-53ch` の状態（○ または 空欄）を、PDFテーブル最下行右端の小さな枠に描画。
-   **1.2G L,M,H**: 1.2G列の右端の赤いセルに描画。

## 5. 使用場所・チャンネルリスト (下段 1〜4枠)
キープリスト内の施設データと、フォームで入力された個別の日程を反映。

| PDF項目名 | データソース | 備考 |
| :--- | :--- | :--- |
| 日付 | `start_date` 〜 `end_date` | |
| 時間 | `start_time` 〜 `end_time` | |
| 〒 | `Facility.postal_code` | |
| 住所 | `Facility.prefecture` + `Facility.address` | |
| 施設名 | `Facility.name` | |
| 屋内/屋外 | `Facility.category` | 「屋内」か「屋外」の該当枠を囲むか印を付ける |
| 適用エリア名称 | `Facility.applied_area` | |
| 使用TVチャンネル | `Facility.selectedChannels` | 昇順・カンマ区切り (例: 13, 14, 48) |

## 6. 実装上の注意
-   **フォント**: Web UIとデザインを統一するため、`static/fonts/NotoSansJP-Regular.ttf` を使用する。日本語の文字化けを防ぐため、ReportLab等でのフォント登録が必須。
-   **1.2GのmW**: 1.2G帯についてはPDF上に「10mW」「20mW」「50mW」の入力欄があるが、基本は「L,M,H」の枠を使用する。
