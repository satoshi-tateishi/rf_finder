# 施設データの郵便番号付与およびインポート手順

本ドキュメントでは、総務省公表の施設データ（CSV）に対して郵便番号を自動付与し、MySQLデータベースにインポートする手順を説明します。

## 1. 概要
施設データ（`locations.csv`）には郵便番号が含まれていないため、日本郵便の郵便番号データ（`utf_ken_all.csv`）と住所照合を行い、郵便番号付きの `locations_with_zip.csv` を生成します。その後、Djangoの管理コマンドを使用してデータベースへインポートします。

## 2. 必要ファイル
以下のファイルが `csv/` ディレクトリに配置されている必要があります。

| ファイル名 | 内容 | 備考 |
| :--- | :--- | :--- |
| `locations.csv` | 総務省公表の施設リスト | インポート元データ |
| `utf_ken_all.csv` | 日本郵便の郵便番号データ | UTF-8形式、BOMなし |
| `devices.csv` | ワイヤレス機器マスタ | 同時にインポートされる機器情報 |

## 3. 郵便番号付与プロセスの実行
郵便番号を付与し、インポート用のCSVを生成します。

### 実行スクリプト
`csv/generate_facility_data.py`

### 実行コマンド
```bash
python3 csv/generate_facility_data.py
```

### 処理内容
1.  **住所の正規化**: 照合精度を高めるため、以下の処理を行います。
    *   Unicode正規化 (NFKC)
    *   漢数字の英数字変換 (一二三 → 123)
    *   丁目・番地・号の表記ゆれ修正
2.  **住所照合**: 郵便番号データの「都道府県 + 市区町村 + 町域」と施設データの「都道府県 + 住所」を照合します。
    *   より詳細な住所に一致させるため、住所文字列の長い順にマッチングを試行します。
3.  **53CHの補完**: 全ての施設に対して `53CH` カラムに `○` を設定します。
4.  **出力**: `csv/locations_with_zip.csv` をBOM付きUTF-8（Excel対応）で出力します。

## 4. データベースへのインポート
生成したCSVをMySQLにインポートします。この操作は既存のデータを全て削除（Truncate相当）してから行われます。

### 実行コマンド
```bash
docker-compose exec web python manage.py import_csv
```

### 内部処理
*   `WirelessEquipment` (機器情報) の全削除と再登録。
*   `Facility` (施設情報) の全削除と再登録。
*   `TVChannelStatus` (チャンネル空き状況) の自動生成（13CH〜53CH）。
    *   `Facility` 削除時に CASCADE により自動削除されます。

## 5. 注意事項
*   **住所の不一致**: 住所表記が特殊な場合（ビル名のみ、地番が古い等）、郵便番号が空欄になることがあります。今回の実行では約99.8%の照合率を確認しています。
*   **エンコーディング**: `import_csv` コマンドはBOM付きUTF-8 (`utf-8-sig`) を想定しています。
*   **データの更新**: 総務省のデータが更新された場合は、`locations.csv` を差し替えて手順3から再実行してください。
